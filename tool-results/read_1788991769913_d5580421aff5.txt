    69→## 3. 상태 관리 설계
    70→
    71→### 3.1 Zustand Store: `kiosk-store.ts`
    72→
    73→파일 경로: `src/store/kiosk-store.ts`
    74→
    75→#### Screen 타입 유니언
    76→
    77→```typescript
    78→export type Screen =
    79→  | 'standby'
    80→  | 'main'
    81→  | 'equipment-intro'
    82→  | 'location'
    83→  | 'app-install'
    84→  | 'signup'
    85→  | 'vein-register'
    86→  | 'login'
    87→  | 'non-member'
    88→  | 'measurement-mode'
    89→  | 'measurement-equipment'
    90→  | 'results'
    91→  | 'completion';
    92→```
    93→
    94→#### Store 인터페이스
    95→
    96→```typescript
    97→interface KioskState {
    98→  // ── 내비게이션 ──
    99→  currentScreen: Screen;         // 현재 화면
   100→  history: Screen[];             // 뒤로가기용 히스토리 스택
   101→
   102→  // ── 세션 ──
   103→  sessionId: string;             // 익명 세션 ID (랜덤 문자열)
   104→  sessionStarted: boolean;       // 세션 활성 여부
   105→
   106→  // ── 디바이스 ──
   107→  isMobile: boolean;             // 768px 미만 여부
   108→
   109→  // ── 진행 추적 ──
   110→  visitedScreens: Set<Screen>;   // 방문 완료 화면 집합
   111→
   112→  // ── 접근성 ──
   113→  fontSize: 'normal' | 'large' | 'xlarge';  // 글꼴 크기
   114→  ttsEnabled: boolean;           // TTS 음성 안내 활성 여부
   115→  highContrast: boolean;         // 고대비 모드 활성 여부
   116→
   117→  // ── 타이머 ──
   118→  idleTimer: ReturnType<typeof setTimeout> | null;  // 유휴 타임아웃 핸들
   119→
   120→  // ── 액션 ──
   121→  navigateTo: (screen: Screen) => void;   // 화면 이동
   122→  goBack: () => void;                     // 뒤로가기
   123→  goHome: () => void;                     // 홈 이동
   124→  startSession: () => void;               // 세션 시작
   125→  endSession: () => void;                 // 세션 종료
   126→  resetToStandby: () => void;             // 강제 대기 복귀
   127→  setMobile: (v: boolean) => void;        // 모바일 여부 설정
   128→  setFontSize: (s: ...) => void;          // 글꼴 크기 설정
   129→  setTtsEnabled: (v: boolean) => void;    // TTS 토글
   130→  setHighContrast: (v: boolean) => void;  // 고대비 토글
   131→  resetIdleTimer: () => void;             // 유휴 타이머 리셋
   132→}
   133→```
   134→
   135→#### 핵심 로직
   136→
   137→| 액션 | 동작 |
   138→|------|------|
   139→| `navigateTo(screen)` | `history`에 `currentScreen` 푸시 → `currentScreen` 변경 → `visitedScreens`에 추가 → `logEvent(screen, 'navigate', from)` → `resetIdleTimer()` |
   140→| `goBack()` | `history` 팝 → 이전 화면 복원 → `logEvent` → `resetIdleTimer()` |
   141→| `goHome()` | `currentScreen = 'main'`, `history = []` → `logEvent` → `resetIdleTimer()` |
   142→| `startSession()` | 랜덤 `sessionId` 생성 → `currentScreen = 'main'` → `logEvent('main', 'session_start')` → `resetIdleTimer()` |
   143→| `endSession()` | `logEvent('standby', 'session_end')` → `idleTimer` 해제 → 상태 초기화 → `currentScreen = 'standby'` |
   144→| `resetIdleTimer()` | 기존 타이머 해제 → 120초 후 `endSession()` 예약 (세션 활성 시만) |
   145→
   146→#### 진행률 계산
   147→
   148→```typescript
   149→const TOTAL_CONTENT_SCREENS: Screen[] = [
   150→  'equipment-intro', 'location', 'app-install', 'signup',
   151→  'vein-register', 'login', 'non-member', 'measurement-mode',
   152→  'measurement-equipment', 'results',
   153→]; // 10개
   154→
   155→export function useProgress() {
   156→  const visited = useKioskStore((s) => s.visitedScreens);
   157→  const visitedCount = TOTAL_CONTENT_SCREENS.filter((s) => visited.has(s)).length;
   158→  return {
   159→    visitedCount,         // 방문 완료 화면 수
   160→    total: 10,            // 전체 콘텐츠 화면 수
   161→    percent: Math.round((visitedCount / 10) * 100),  // 백분율
   162→  };
   163→}
   164→```
   165→
   166→#### 익명 로깅 함수
   167→
   168→```typescript
   169→async function logEvent(screen: string, eventType: string, from?: string) {
   170→  await fetch('/api/logs', {
   171→    method: 'POST',
   172→    headers: { 'Content-Type': 'application/json' },
   173→    body: JSON.stringify({
   174→      sessionId: state.sessionId || 'standby',
   175→      eventType,
   176→      screen,
   177→      detail: from || '',
   178→    }),
   179→  });
   180→}
   181→```
   182→
   183→- 개인식별정보 불포함 (세션 ID는 랜덤 문자열)
   184→- `fetch` 실패 시 무시 (Silent fail)

   188→## 4. 화면 전환 메커니즘
   189→
   190→### 4.1 AnimatePresence + motion.div
   191→
   192→`src/app/page.tsx`에서 Framer Motion의 `AnimatePresence`와 `motion.div`를 사용하여 화면 전환 애니메이션 구현:
   193→
   194→```typescript
   195→const pageVariants = {
   196→  initial: { opacity: 0, y: 20 },   // 아래에서 페이드인
   197→  animate: { opacity: 1, y: 0 },     // 정지
   198→  exit:    { opacity: 0, y: -20 },   // 위로 페이드아웃
   199→};
   200→
   201→<AnimatePresence mode="wait">
   202→  <motion.div
   203→    key={currentScreen}           // 화면 변경 시 리마운트 트리거
   204→    variants={pageVariants}
   205→    initial="initial"
   206→    animate="animate"
   207→    exit="exit"
   208→    transition={{ duration: 0.25, ease: 'easeInOut' }}
   209→  >
   210→    <ScreenRenderer screen={currentScreen} />
   211→  </motion.div>
   212→</AnimatePresence>
   213→```
   214→
   215→- `mode="wait"`: 퇴장(exit) 애니메이션 완료 후 입장(initial) 애니메이션 시작
   216→- `key={currentScreen}`: 화면 ID가 변경되면 React가 컴포넌트를 리마운트하여 전환 트리거
   217→- 전환 시간: **0.25초** (NFR-05: 3초 이내 만족)
   218→
   219→### 4.2 ScreenRenderer
   220→
   221→`currentScreen` 값에 따른 switch 문으로 13개 화면 컴포넌트를 렌더링:
   222→
   223→```typescript
   224→function ScreenRenderer({ screen }: { screen: Screen }) {
   225→  switch (screen) {
   226→    case 'standby':              return <StandbyScreen />;
   227→    case 'main':                 return <MainMenu />;
   228→    case 'equipment-intro':      return <EquipmentIntro />;
   229→    case 'location':             return <LocationGuide />;
   230→    case 'app-install':          return <AppInstall />;
   231→    case 'signup':               return <Signup />;
   232→    case 'vein-register':        return <VeinRegister />;
   233→    case 'login':                return <LoginGuide />;
   234→    case 'non-member':           return <NonMember />;
   235→    case 'measurement-mode':     return <MeasurementMode />;
   236→    case 'measurement-equipment': return <MeasurementEquipment />;
   237→    case 'results':              return <ResultsGuide />;
   238→    case 'completion':           return <CompletionScreen />;
   239→    default:                     return <MainMenu />;
   240→  }
   241→}
   242→```
   243→
   244→### 4.3 Zustand 내비게이션
   245→
   246→화면 전환은 Zustand store의 액션을 통해서만 수행:
   247→
   248→```
   249→사용자 터치/클릭
   250→    → navigateTo('equipment-intro')
   251→        → history.push(currentScreen)
   252→        → currentScreen = 'equipment-intro'
   253→        → visitedScreens.add('equipment-intro')
   254→        → logEvent(...)
   255→        → resetIdleTimer()
   256→    → React 리렌더: ScreenRenderer 교체
   257→    → Framer Motion: exit → initial → animate
   258→```

   264→### 5.1 useTTS 훅
   265→
   266→파일 경로: `src/hooks/use-tts.ts`
   267→
   268→```typescript
   269→const SPEECH_RATE = 0.85;   // 어르신 배려 느린 속도
   270→const SPEECH_PITCH = 1.0;
   271→const SPEECH_VOLUME = 1.0;
   272→```
   273→
   274→#### 인터페이스
   275→
   276→```typescript
   277→interface UseTTSOptions {
   278→  autoSpeak?: boolean;  // 화면 전환 시 자동 읽기 여부
   279→}
   280→
   281→function useTTS(options?: UseTTSOptions): {
   282→  speak: (text: string) => void;      // 임의 텍스트 읽기
   283→  speakIntro: () => void;             // 현재 화면 intro 읽기
   284→  speakFull: () => void;              // 현재 화면 full 읽기
   285→  stop: () => void;                   // 음성 정지
   286→}
   287→```
   288→
   289→#### 한국어 음성 엔진 자동 탐지
   290→
   291→```typescript
   292→const getKoreanVoice = (): SpeechSynthesisVoice | null => {
   293→  const voices = window.speechSynthesis.getVoices();
   294→  // 1순위: lang이 'ko'로 시작하는 음성
   295→  const krVoice = voices.find((v) => v.lang.startsWith('ko'));
   296→  if (krVoice) return krVoice;
   297→  // 2순위: 'KO', 'kr', 'Korean' 포함 음성
   298→  const krLike = voices.find((v) =>
   299→    v.lang.includes('KO') || v.lang.includes('kr') || v.name.includes('Korean')
   300→  );
   301→  return krLike || voices[0] || null;
   302→};
   303→```
   304→
   305→#### 자동 읽기 흐름
   306→
   307→```
   308→화면 전환 (currentScreen 변경)
   309→    → ttsEnabled === true ?
   310→        → prevScreenRef !== currentScreen ?
   311→            → voices 로드 대기 (voiceschanged 이벤트)
   312→            → speakIntro() 호출
   313→                → ttsTexts[currentScreen].intro 텍스트
   314→                → SpeechSynthesisUtterance 생성
   315→                → rate=0.85, voice=한국어음성
   316→                → speechSynthesis.speak()
   317→```
   318→
   319→- `autoSpeak: true`는 `page.tsx`에서만 설정 → 이중 재생 방지
   320→- `ttsEnabled === false` 전환 시 `speechSynthesis.cancel()` 즉시 정지
   321→- 언마운트 시 `cancel()` 정리
   322→
   323→### 5.2 tts-texts.ts: 화면별 음성 안내 텍스트

   325→파일 경로: `src/lib/tts-texts.ts`
   326→
   327→```typescript
   328→export interface TTSContent {
   329→  intro: string;   // 화면 진입 시 자동 읽기 (요약)
   330→  full?: string;   // "다시 듣기" 버튼으로 전체 읽기

   332→
   333→export const ttsTexts: Record<Screen, TTSContent> = {
   334→  standby:   { intro: '바이오그램 미니…화면을 터치하시면…' },
   335→  main:      { intro: '메인 메뉴입니다…', full: '총 10개의 교육 항목이…' },

   339→
   340→- `intro`: 간결한 요약 (화면 진입 시 자동 재생)

   355→## 6. 고대비 구현
   356→
   357→### 6.1 CSS `.high-contrast` 클래스
   358→
   359→`globals.css`에서 oklch CSS 변수를 오버라이드:
   360→
   361→```css
   362→.high-contrast {
   363→  --background: oklch(0.08 0 0);         /* 거의 검정 */
   364→  --foreground: oklch(1 0 0);            /* 순백 */
   365→  --card: oklch(0.12 0 0);               /* 어두운 카드 */
   366→  --primary: oklch(0.85 0.18 145);       /* 밝은 녹색 액센트 */
   367→  --border: oklch(0.5 0 0);              /* 중간 회색 보더 */
   368→  /* ... 모든 디자인 토큰 오버라이드 */
   369→}
   370→```
   371→
   372→#### 강화 스타일
   373→
   374→| 요소 | 일반 | 고대비 |
   375→|------|------|--------|
   376→| 카드 보더 | 1px | 3px, 명도 0.7 |
   377→| 카드 hover 보더 | primary 자동 | 명도 0.85 녹색 |
   378→| 주 버튼 | font-weight 600 | font-weight **800**, 3px 백색 보더 |
   379→| 외곽 버튼 | 2px 보더 | 3px 보더, font-weight 800 |
   380→| 경고 박스 | 2px amber | 3px 고대비 amber |
   381→| 측정 카드 좌 보더 | 4px 컬러 | 6px 고대비 컬러 |
   382→| 이미지 | 보더 없음 | 2px 회색 보더 |
   383→| 스크롤바 thumb | primary/20 | 명도 0.7 |
   384→
   385→### 6.2 Hydration Mismatch 방지
   386→
   387→고대비 클래스 토글 시 서버-클라이언트 HTML 불일치(hydration mismatch)를 방지하기 위해 `useEffect` + `ref`로 DOM 직접 조작:
   388→
   389→```typescript
   390→const containerRef = useRef<HTMLDivElement>(null);
   391→
   392→useEffect(() => {
   393→  const el = containerRef.current;
   394→  if (!el) return;
   395→  el.classList.toggle('high-contrast', highContrast);
   396→}, [highContrast, ...]);
   397→
   398→return (
   399→  <AnimatePresence mode="wait">
   400→    <motion.div ref={containerRef} key={currentScreen} ...>
   401→      <ScreenRenderer screen={currentScreen} />
   402→    </motion.div>
   403→  </AnimatePresence>
   404→);
   405→```
   406→
   407→- 서버 렌더링 시에는 클래스 미적용 → HTML 일치
   408→- 클라이언트 마운트 후 `useEffect`에서 클래스 토글 → hydration 충돌 없음

   412→## 7. 글꼴 크기 구현
   413→
   414→### 7.1 CSS zoom 속성
   415→
   416→```typescript
   417→const zoomValue = fontSize === 'normal' ? 1 : fontSize === 'large' ? 1.15 : 1.3;
   418→
   419→useEffect(() => {
   420→  const el = containerRef.current;
   421→  if (!el) return;
   422→  el.style.zoom = fontSize === 'normal' ? '' : String(zoomValue);
   423→}, [fontSize, ...]);
   424→```
   425→
   426→| 설정 | zoom 값 | 효과 |
   427→|------|---------|------|
   428→| 보통 | 1 (빈 문자열) | 기본 크기 |
   429→| 크게 | 1.15 | 15% 확대 |
   430→| 아주 크게 | 1.3 | 30% 확대 |
   431→
   432→- `zoom` 속성 사용 이유: `transform: scale()`과 달리 레이아웃 흐름에 반영되어 스크롤·레이아웃 깨짐 없음
   433→- `useEffect` + `ref` 적용으로 hydration mismatch 방지 (고대비와 동일 패턴)
   434→
   435→### 7.2 접근성 툴바 글꼴 크기 버튼
   436→
   437→```typescript
   438→const sizeOptions: SizeOption[] = [
   439→  { value: 'normal', label: '보통',   display: 'A', textSize: 'text-sm'   },
   440→  { value: 'large',  label: '크게',   display: 'A', textSize: 'text-lg'   },
   441→  { value: 'xlarge', label: '아주 크게', display: 'A', textSize: 'text-2xl' },
   442→];
   443→```
   444→
   445→- 버튼 내 글자 크기(`display`)로 시각적 크기 차이 표현
   446→- `aria-pressed` 속성으로 현재 선택 상태 스크린 리더 전달

   541→model KioskContent {

   550→}
   551→
   552→model KioskLog {
   553→  id        String   @id @default(cuid())
   554→  sessionId String?               // 익명 세션 ID
   555→  eventType String                 // navigate | back | home | session_start | session_end | idle_timeout
   556→  screen    String?               // 이벤트 발생 화면
   557→  detail    String?               // 부가 정보 (from 화면 등)
   558→  createdAt DateTime @default(now())
   559→}
   560→
   561→model KioskSession {
   562→  id        String   @id @default(cuid())
   563→  startedAt DateTime @default(now())
   564→  endedAt   DateTime?             // 세션 종료 시각 (null = 진행 중)
   565→}

   590→## 10. API 설계
   591→
   592→### 10.1 `/api/logs`
   593→
   594→파일 경로: `src/app/api/logs/route.ts`
   595→
   596→| 메서드 | 용도 | 요청 | 응답 |
   597→|--------|------|------|------|
   598→| **POST** | 이벤트 로그 기록 | `{ sessionId, eventType, screen?, detail? }` | `{ success: true }` 또는 `{ error }` 400/500 |
   599→| **GET** | 최근 로그 조회 (최대 100건) | — | `KioskLog[]` (createdAt DESC) |
   600→
   601→#### POST 유효성 검증
   602→
   603→- `sessionId`: 필수 (누락 시 400)
   604→- `eventType`: 필수 (누락 시 400)
   605→- `screen`, `detail`: 선택
   606→
   607→#### GET 정렬
   608→
   609→- `orderBy: { createdAt: 'desc' }`, `take: 100`
   610→
   611→### 10.2 `/api/content`
   612→
   613→파일 경로: `src/app/api/content/route.ts`
   614→
   615→| 메서드 | 용도 | 요청 | 응답 |
   616→|--------|------|------|------|
   617→| **GET** | 전체 콘텐츠 조회 | — | `KioskContent[]` (section ASC) |
   618→| **PUT** | 콘텐츠 upsert | `{ section, title, body?, imageUrl?, qrCodeUrl? }` | upsert 결과 `KioskContent` |
   619→
   620→#### PUT Upsert 로직
   621→
   622→```typescript
   623→await db.kioskContent.upsert({
   624→  where: { section },
   625→  update: { title, body, imageUrl, qrCodeUrl },
   626→  create: { section, title, body, imageUrl, qrCodeUrl },
   627→});
   628→```
   629→
   630→- 동일 `section`이면 업데이트, 없으면 생성 → 관리자 CMS에서 안전한 편집

   789→## 14. 모바일 vs 데스크톱 분기
   790→
   791→| 요소 | 모바일 (<768px) | 데스크톱 (≥768px) |
   792→|------|-----------------|-------------------|
   793→| **접근성 툴바** | 상단 인라인 (`MobileToolbar`) | 우측 상단 플로팅 버튼 → 확장 패널 (`DesktopToolbar`) |
   794→| **하단 네비** | 고정 탭바 (`MobileBottomNav`, 5개 탭) | 숨김 |
   795→| **카드 그리드** | 1열 | 2~4열 |
   796→| **버튼 크기** | 전폭 (`w-full`) | 자동 폭 |
   797→| **PWA 설치 버튼** | `bottom-20 right-4` (탭바 위) | `bottom-4 right-4` |

   832→## 16. 성능 고려사항
   833→
   834→| 항목 | 전략 |
   835→|------|------|
   836→| **초기 로딩** | Next.js 자동 코드 분할, Noto Sans KR 다이나믹 서브셋 (`display: swap`) |
   837→| **화면 전환** | Framer Motion 0.25초 트랜지션, `mode="wait"`으로 동시 마운트 방지 |
   838→| **TTS** | Web Speech API는 브라우저 내장 (별도 다운로드 없음), 음성 엔진 OS 캐시 |
   839→| **이미지** | 정적 이미지 SW 프리캐시, `<Image>` 컴포넌트 미사용 (키오스크 고정 해상도) |
   840→| **로깅** | `fetch` 실패 시 무시 (UI 블로킹 없음), 비동기 fire-and-forget |
   841→| **오프라인** | SW cache-first로 정적 자산 즉시 로드, API는 네트워크 전용 |
   842→| **글꼴 크기** | CSS `zoom` 속성으로 reflow 최소화 (transform보다 레이아웃 비용 낮음) |
   843→| **Zustand** | 단일 스토어로 상태 동결화, 불필요한 리렌더 방지 selector 사용 |
