# Biogram MINI 헬스케어 장비 이용 교육 키오스크 — 제품 요구사항 문서 (PRD)

> 버전: 1.0.0  
> 최종 수정: 2026-03-05  
> 작성자: Biogram MINI 개발팀

---

## 1. 제품 개요

| 항목 | 내용 |
|------|------|
| **제품명** | Biogram MINI 헬스케어 장비 이용 교육 키오스크 |
| **유형** | 웹 기반 대면형 교육 키오스크 (PWA) |
| **핵심 성격** | **실제 측정을 수행하지 않으며, 오직 장비 이용법 교육만 제공** |
| **대상 플랫폼** | 키오스크 터치스크린, 모바일 브라우저, 데스크톱 브라우저 |
| **주요 언어** | 한국어 (ko-KR) |

본 제품은 보건소·건강센터 등에 설치된 **바이오그램 MINI** 헬스케어 통합 측정 장비의 **이용 방법을 교육**하기 위한 키오스크 애플리케이션이다. 사용자는 본 키오스크를 통해 장비 소개, 앱 설치·가입 방법, 정맥 등록, 측정 순서, 결과 확인 방법 등을 단계별로 학습할 수 있다. **실제 생체 측정은 수행하지 않으며**, 장비와의 통신(Bluetooth, Wi-Fi 등)도 하지 않는다.

---

## 2. 비즈니스 배경

### 2.1 문제 정의

- **노인층 디지털 소외**: 65세 이상 노인 인구 중 스마트폰 앱 설치·회원가입·QR코드 스캔 등 디지털 과정에 어려움을 겪는 비율이 높음.
- **장비 이용률 저조**: 보건소에 설치된 바이오그램 MINI 장비의 실제 이용률이 기대에 미치지 못함. 주요 원인은 사용법 미숙지.
- **현장 안내 인력 부족**: 보건소 직원이 1:1로 장비 사용법을 안내하기 어려운 상황.

### 2.2 비즈니스 목표

1. 장비 이용 전 사전 교육을 통해 **실제 측정 시간 단축** (1인당 측정 소요 시간 30% 감소 목표)
2. 노인층의 **디지털 접근성 장벽 해소** (앱 설치·가입 완료율 20%p 향상)
3. 현장 인력 개입 최소화 → **운영 효율화**
4. 교육 키오스크 설치 후 **장비 일일 이용 건수 50% 증가** 목표

|---|------|-----------|

## 4. 사용자 페르소나

### P-1: 김순자 (75세, 일반 방문객)

- **배경**: 스마트폰 사용 경험 있으나 앱 설치·가입에 어려움. 글씨가 잘 안 보임.
- **니즈**: 큰 글씨, 음성 안내, 단순한 터치 조작.
- **불안**: "잘못 누르면 어떡하지?", "내 정보가 새어나가면?"

### P-2: 이영수 (68세, 보건소 정기 방문객)

- **배경**: 기본적인 스마트폰 조작 가능. 앱 사용 경험 있음.
- **니즈**: 측정 순서와 각 장비 사용법을 빠르게 확인.
- **목표**: 대기 시간 중 미리 사용법 학습.

### P-3: 박미영 (42세, 보건소 직원)

- **배경**: 디지털 친숙. 방문객에게 장비 사용법을 설명하는 역할.
- **니즈**: 방문객이 자율적으로 교육받을 수 있는 시스템. 세션 로그로 방문객 이해도 파악.
- **목표**: 반복 안내 업무 감소.

### P-4: 최준호 (55세, 일반 방문객)

- **배경**: 회원가입을 원치 않음. 비회원으로 측정 가능한지 궁금.
- **니즈**: 비회원 이용 방법 안내.

## 5. 제약사항

| ID | 제약 내용 | 근거 |
|----|-----------|------|
| C-1 | **실제 생체 측정 금지** — 본 키오스크는 교육 전용으로, 어떠한 생체 신호(신장, 체중, 혈압 등)도 측정하지 않음 | 제품 정의, 법적·윤리적 안전 |
| C-2 | **개인정보 입력 금지** — 이름, 주민등록번호, 전화번호 등 개인식별정보를 입력받지 않음 | 최소정보원칙, 개인정보보호법 |
| C-3 | **장비 통신 금지** — Bluetooth, Wi-Fi, USB 등 어떠한 통신 방식으로도 바이오그램 MINI 장비와 직접 연결하지 않음 | 보안, 단순성 |
| C-4 | **오프라인 동작 보장** — 네트워크 단절 시에도 핵심 교육 콘텐츠 열람 가능 (PWA Service Worker 캐시) | 보건소 네트워크 불안정 |
| C-5 | **단일 언어** — UI 및 TTS 음성은 한국어만 지원 | 타겟 사용자 |
| C-6 | **유휴 타임아웃 120초** — 사용자 조작 없이 120초 경과 시 자동으로 대기(standby) 화면 복귀 | 키오스크 공유 환경, 세션 격리 |

## 6. 범위

### 6.1 화면 구성 (총 13개)

| # | 화면 ID | 화면명 | 설명 |
|---|---------|--------|------|
| 1 | `standby` | 대기 화면 | 키오스크 유휴 상태. 터치 시 세션 시작 |
| 2 | `main` | 메인 메뉴 | 10개 교육 항목 카드 그리드 |
| 3 | `equipment-intro` | 장비 소개 | 바이오그램 MINI 측정 항목 7가지 소개 |
| 4 | `location` | 설치 위치 안내 | 장비 설치 장소, 이용 시간 안내 |
| 5 | `app-install` | 앱 설치 안내 | App Store/Play Store, QR코드 설치 방법 |
| 6 | `signup` | 회원가입 안내 | 앱 회원가입 4단계 안내 |
| 7 | `vein-register` | 지정맥 등록 안내 | 정맥 인식 등록 방법, 주의사항 |
| 8 | `login` | 로그인 안내 | 지정맥 로그인, QR코드 로그인 방법 |
| 9 | `non-member` | 비회원 이용 안내 | 회원가입 없이 이용하는 방법 |
| 10 | `measurement-mode` | 측정 모드 안내 | 6가지 측정 순서, 전체 소요 시간 |
| 11 | `measurement-equipment` | 측정 장비 안내 | 각 장비별 사용법, 주의사항 상세 |
| 12 | `results` | 결과 확인 안내 | 측정 결과 확인 3가지 방법 |
| 13 | `completion` | 교육 완료 | 전체 교육 완료 축하, 요약 |

### 6.2 범위 외 (Out of Scope)

- 실제 생체 측정 기능
- 사용자 계정 생성·인증
- 장비 원격 제어·상태 모니터링
- 다국어 지원 (영어, 중국어 등)
- 관리자 대시보드 (별도 프로젝트)
- 결제·예약 기능

## 7. 기능 요구사항

### 7.1 화면 전환 및 내비게이션

| ID | 요구사항 | 상세 |
|----|----------|------|
| FR-01 | **화면 전환** | 사용자가 메뉴를 선택하면 해당 교육 화면으로 전환. Framer Motion `AnimatePresence`를 이용한 부드러운 슬라이드 전환 (0.25초) |
| FR-02 | **뒤로가기** | 모든 콘텐츠 화면에서 이전 화면으로 복귀. Zustand 내비게이션 히스토리 스택 기반 |
| FR-03 | **홈 이동** | 언제든지 메인 메뉴(main)로 즉시 이동. 히스토리 스택 초기화 |
| FR-04 | **유휴 타임아웃** | 세션 활성 상태에서 사용자 조작(touchstart, mousedown, keydown, scroll) 없이 **120초** 경과 시 자동 종료 → standby 화면 |
| FR-05 | **세션 시작** | standby 화면 터치 시 익명 세션 ID 생성, main 화면 진입 |
| FR-06 | **세션 종료** | completion 화면 도달, 유휴 타임아웃, 또는 사용자 명시적 종료 시 세션 종료 → standby 복귀 |

### 7.2 로깅 및 진행 추적

| ID | 요구사항 | 상세 |
|----|----------|------|
| FR-07 | **익명 세션 로깅** | 화면 전환, 뒤로가기, 홈 이동, 세션 시작/종료, 유휴 타임아웃 이벤트를 `/api/logs` POST로 기록. 세션 ID는 랜덤 문자열로 개인식별정보 불포함 |
| FR-08 | **진행률 추적** | 10개 콘텐츠 화면 중 방문 완료된 화면 수를 `visitedScreens: Set<Screen>`으로 추적. 진행률 백분율 `(방문수 / 10) × 100` 실시간 계산 |

### 7.3 접근성

| ID | 요구사항 | 상세 |
|----|----------|------|
| FR-09 | **TTS 음성 안내** | Web Speech API 기반 화면별 음성 안내. 화면 진입 시 intro 텍스트 자동 읽기, "다시 듣기" 버튼으로 요약/전체 재생. 한국어 음성 엔진 자동 탐지, 어르신 배려 speech rate 0.85 |
| FR-10 | **고대비 모드** | `.high-contrast` CSS 클래스로 oklch 변수 오버라이드. 배경 검정·전경 백 최대 대비, 보더 3px 강화, 버튼 font-weight 800 |
| FR-11 | **글꼴 크기 조절** | 3단계: 보통(1.0), 크게(1.15), 아주 크게(1.3). CSS `zoom` 속성 적용 |
| FR-12 | **접근성 툴바** | 데스크톱: 우측 상단 플로팅 버튼 → 확장 패널. 모바일: 상단 인라인 툴바. 글꼴 크기, TTS 켜짐/꺼짐, 고대비 켜짐/꺼짐 제어 |

### 7.4 플랫폼·UI

| ID | 요구사항 | 상세 |

## 9. 성공 지표

| 지표 | 측정 방법 | 목표치 |
|------|-----------|--------|
| **세션 완료율** | completion 화면 도달 세션 / 전체 세션 | ≥ 70% |
| **평균 체류 시간** | 세션 종료 시각 - 세션 시작 시각 평균 | 3~8분 |
| **화면별 이탈률** | 각 화면에서 뒤로가기/홈 이동 비율 | 각 화면 ≤ 20% |
| **접근성 기능 사용률** | TTS 활성 세션 비율, 고대비 활성 세션 비율, 글꼴 확대 세션 비율 | TTS ≥ 30%, 고대비 ≥ 15%, 글꼴 확대 ≥ 25% |
| **유휴 타임아웃 발생률** | idle_timeout 이벤트 / 전체 세션 | ≤ 25% |
| **앱 설치 화면 체류 시간** | app-install 화면 평균 체류 시간 | ≥ 60초 |
| **측정 안내 화면 방문률** | measurement-mode 화면 방문 세션 / 전체 세션 | ≥ 80% |

## 10. 화면 흐름도

```
[standby] ──(터치)──▶ [main]
                         │
          ┌──────────────┼──────────────┐
          │              │              │
   [equipment-intro] [location]   [app-install]
          │              │              │
       [signup]   [vein-register]  [login]
          │              │              │
    [non-member] [measurement-mode] [measurement-equipment]
          │              │              │
       [results] ─────────┘              │
          │                               │
          └──────────▶ [completion] ◀─────┘
```

- 모든 콘텐츠 화면에서 **뒤로가기**(←) 및 **홈**(🏠) 이동 가능
- `completion` 화면에서 세션 종료 → `standby` 복귀
- 120초 무조작 시 어느 화면에서든 → `standby` 복귀

## 11. 용어 정의

| 용어 | 정의 |
|------|------|
| **바이오그램 MINI** | 7가지 건강 지표를 측정하는 통합 헬스케어 장비 |
| **지정맥(指靜脈)** | 손등의 정맥 패턴을 이용한 생체 인식 방식 |
| **세션** | 사용자가 standby 화면를 터치하여 시작하고 completion 또는 타임아웃으로 종료되는 일련의 화면 방문 단위 |
| **TTS** | Text-to-Speech. 텍스트를 음성으로 변환하여 출력하는 기술 |
| **고대비 모드** | 배경을 검정, 전경을 백색으로 하여 시각 대비를 최대화하는 접근성 모드 |
| **PWA** | Progressive Web App. Service Worker를 통한 오프라인 동작 및 설치 기능을 갖춘 웹 앱 |
| **유휴 타임아웃** | 사용자 조작이 없는 상태로 일정 시간 경과 후 자동 화면 복귀하는 기능 |
