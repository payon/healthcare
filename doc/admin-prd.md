## 1. 제품 개요

| 항목 | 내용 |
|------|------|
| **제품명** | Biogram MINI 관리자 대시보드 |
| **유형** | 웹 기반 콘텐츠 관리 시스템 (CMS) |
| **핵심 성격** | 키오스크 프론트엔드에 표시되는 **모든 텍스트·이미지를 실시간으로 관리**하는 백오피스 시스템 |
| **대상 플랫폼** | 데스크톱 브라우저 (관리자용), 태블릿, 모바일 (긴급 수정 시) |
| **주요 언어** | 한국어 (ko-KR), UI 라벨은 한국어 |
| **연동 시스템** | Biogram MINI 키오스크 프론트엔드 (13개 화면) |

본 제품은 보건소·건강센터에 설치된 **바이오그램 MINI 헬스케어 장비 교육 키오스크**의 모든 콘텐츠를 원격으로 관리하기 위한 **백엔드 관리자 대시보드**이다. 관리자는 본 대시보드를 통해 키오스크 13개 화면의 텍스트·이미지를 수정하고, 6가지 측정 항목별 장비 정보를 개별 관리하며, 변경 사항이 **키오스크에 즉시 반영**되도록 한다.

## 2. 비즈니스 배경

### 2.1 문제 정의

- **콘텐츠 수정 의존도**: 현재 키오스크 콘텐츠 변경 시 개발자가 코드를 직접 수정해야 하며, 비개발 직원이 자율적으로 내용을 갱신할 수 없음.
- **측정 항목 정보 갱신 어려움**: 장비 사양 변경, 측정 방법 업데이트, 주의사항 추가 등이 빈번하나 즉각 반영이 불가능.
- **다중 설치 환경**: 동일 키오스크가 여러 보건소에 설치될 수 있으나, 현재는 설치별 콘텐츠 커스터마이징 불가.
- **운영 이력 추적 부재**: 누가 언제 어떤 콘텐츠를 변경했는지 추적할 수 없어 책임 소재 파악 곤란.

### 2.2 비즈니스 목표

1. **비개발자 자율 관리**: 보건소 직원이 개발자 개입 없이 콘텐츠를 수정 가능 → 수정 리드타임 0일
2. **즉시 반영**: 관리자 대시보드 변경이 키오스크에 **5초 이내** 반영
3. **측정 항목별 독립 관리**: 6가지 측정 항목(신장, 스트레스, 혈압, 악력, 체성분, 피부)의 텍스트·이미지·장비 정보를 개별 CRUD
4. **운영 안전망**: 역할 기반 접근 제어(RBAC)로 무단 변경 방지, 감사 로그로 모든 변경 이력 추적

## 3. 사용자 페르소나

### P-1: 최관리 (45세, 시스템 최고 관리자)

- **역할**: superadmin
- **배경**: IT 부서 책임자. 시스템 전반 관리 권한 보유.
- **니즈**: 관리자 계정 생성/삭제, 전체 시스템 설정, 모든 콘텐츠 수정 권한, 감사 로그 열람.
- **목표**: 시스템 안정성 및 보안 유지, 무단 변경 방지.

### P-2: 이운영 (38세, 보건소 운영 담당)

- **역할**: admin
- **배경**: 보건소 건강검진 프로그램 운영 담당자. 기본적인 웹 관리 경험.
- **니즈**: 측정 항목 정보 갱신, 장비 주의사항 수정, 화면 텍스트/이미지 교체, 대시보드 통계 확인.
- **목표**: 최신 정보를 키오스크에 신속 반영.

### P-3: 박수정 (32세, 콘텐츠 담당)

- **역할**: editor
- **배경**: 홍보팀 소속. 콘텐츠 작성·수정 전담. IT 지식 제한적.
- **니즈**: 키오스크 화면 텍스트 수정, 이미지 업로드/교체, 측정 항목 설명 갱신.
- **불가**: 계정 관리, 시스템 설정 변경 권한 없음.

### P-4: 김조회 (50세, 감사 담당)

- **역할**: viewer
- **배경**: 내부 감사 담당. 시스템 변경 이력 확인 필요.
- **니즈**: 모든 콘텐츠 열람(읽기 전용), 감사 로그 확인, 통계 대시보드 조회.
- **불가**: 어떠한 콘텐츠도 수정할 수 없음.

## 4. 기능 요구사항

### 4.1 인증 및 권한 관리

| ID | 요구사항 | 상세 |
|----|----------|------|
| FR-01 | **로그인** | 이메일 + 비밀번호 로그인. JWT 세션 기반 인증. 로그인 실패 5회 시 15분 계정 잠금 |
| FR-02 | **로그아웃** | 세션 무효화, 클라이언트 토큰 삭제 |
| FR-03 | **세션 관리** | 세션 만료(8시간), 자동 연장(활성 시), 중복 로그인 허용 |
| FR-04 | **RBAC** | 4단계 역할: superadmin > admin > editor > viewer. 각 역할별 허용 작업 매핑 |
| FR-05 | **계정 관리** | superadmin/admin: 계정 생성, 수정, 비활성화. 비밀번호 초기화 |

### 4.2 콘텐츠 관리 (13개 화면)

| ID | 요구사항 | 상세 |
|----|----------|------|
| FR-06 | **화면별 콘텐츠 편집** | 13개 키오스크 화면 각각의 제목, 본문, 이미지를 개별 편집. 리치 텍스트 에디터(Markdown) 지원 |
| FR-07 | **섹션 관리** | 단일 화면 내 다중 섹션(예: measurement-equipment 화면은 6개 장비별 섹션) 개별 편집 |
| FR-08 | **이미지 업로드** | 드래그앤드롭/클릭 이미지 업로드. 지원 포맷: PNG, JPG, WebP, SVG. 최대 5MB. 자동 리사이징(키오스크 해상도 1920×1080 기준) |
| FR-09 | **실시간 미리보기** | 편집 중 콘텐츠를 키오스크 화면 레이아웃으로 실시간 미리보기 |
| FR-10 | **변경 이력** | 콘텐츠별 수정 이력(수정자, 일시, 변경 전/후) 열람. 최근 50개 버전 보관 |

### 4.3 측정 항목 관리 (6가지)

| ID | 요구사항 | 상세 |
|----|----------|------|
| FR-11 | **측정 항목 CRUD** | 6가지 측정 항목(신장, 스트레스, 혈압, 악력, 체성분, 피부)의 이름, 설명, 아이콘, 색상, 순서, 예상 소요 시간, 활성/비활성 관리 |
| FR-12 | **장비 상세 관리** | 각 측정 항목에 대응하는 장비의 이름, 설명, 준비 단계, 주의사항, 이미지를 개별 CRUD |
| FR-13 | **준비 단계 관리** | 장비별 준비 단계(Step 1~N)의 순서, 제목, 설명을 편집. 드래그앤드롭 순서 변경 |
| FR-14 | **주의사항 관리** | 장비별 주의사항 항목 추가/수정/삭제. 중요도 표시(⚠️ 경고, ℹ️ 정보) |

### 4.4 실시간 동기화

| ID | 요구사항 | 상세 |
|----|----------|------|
| FR-15 | **즉시 반영** | 관리자 대시보드에서 저장된 콘텐츠 변경이 키오스크에 **5초 이내** 반영 |
| FR-16 | **SWR 재검증** | 키오스크 클라이언트가 SWR/TanStack Query의 재검증(revalidation)으로 최신 콘텐츠를 자동 fetch |
| FR-17 | **수동 새로고침** | 관리자가 "키오스크 새로고침" 버튼으로 강제 갱신 트리거 가능 |

| FR-19 | **화면별 방문 통계** | 13개 화면 각각의 방문 횟수, 체류 시간, 이�/률 |

## 7. 성공 지표

| 지표 | 측정 방법 | 목표치 |
|------|-----------|--------|
| **콘텐츠 수정 리드타임** | 변경 요청 → 키오스크 반영 시간 | ≤ 5초 |

| **평균 세션 시간** | 관리자 대시보드 평균 체류 시간 | ≤ 15분 (효율적 작업) |

## 8. 범위

### 8.1 In Scope

- 관리자 인증 및 RBAC (4단계 역할)
- 13개 키오스크 화면 콘텐츠 CRUD
- 6가지 측정 항목 및 장비 정보 CRUD
- 이미지 업로드 및 관리
- 실시간 키오스크 반' 동기화 (5초 이내9
4

- 감사 로그
- 반응형 관리 UI

- 키오스크 원격 제어 (전원, 재부팅)

- 알림 시스템 (이메일, SMS, Push)

- 외부 CMS 연동 (WordPress, Strapi 등)
- A/B 테스트 (콘텐츠 변형)
- 모바일 네이티브 앱 (React Native 등)

## 10. 용어 정의

| 용어 | 정의 |
|------|------|
| **관리자 대시보드** | 키오스크 콘텐츠를 관리하는 웹 기반 백오피스 시스템 |
| **RBAC** | Role-Based Access Control. 사용자 역할에 따라 접근 권한을 차등 부여하는 모델 |
| **superadmin** | 최고 관리자. 모든 권한 보유. 역할 변경 및 시스템 설정 가능 |
| **admin** | 운영 관리자. 콘텐츠·계정 관리 가능. 역할 변경 불가 |
| **editor** | 편집자. 콘텐츠·이미지 수정 가능. 계정 관리 불가 |
| **viewer** | 열람자. 읽기 전용. 모든 콘텐츠 열람 가능하나 수정 불가 |
| **감사 로그** | 시스템 내 모든 쓰기 작업의 변경 전/후 값을 기록하는 append-only 로그 |
| **SWR** | Stale-While-Revalidate. 캐시된 데이터를 즉시 제공하면서 백그라운드에서 재검증하는 데이터 패칭 전략 |
